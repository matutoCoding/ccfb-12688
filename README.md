# HoloFan Studio · 全息广告风扇内容编排与上机效果预览系统

纯浏览器端运行的全息风扇（POV 视觉暂留 LED 风扇）内容编排与真机成像预览系统。
**所有素材与数据均在本机处理，不上传任何服务器**：视频 Blob、工程、设备档案存 IndexedDB，
渲染走 WebGL2，产出物（固件二进制包、验收报告）以文件形式交付客户。

## 技术栈

- TypeScript（strict）+ WebGL2，零运行时框架依赖，Vite 构建
- IndexedDB 持久化（素材 Blob / 片段 / LUT / 工程 / 设备 / 校准表 / 风扇墙 / 播放日志）
- 可选 Web Serial 直连真机环境光传感器，不支持时自动回退内置模拟器

## 启动

```bash
npm install
npm run dev      # 开发，默认 http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建，产物在 dist/
npm run preview  # 预览生产构建
```

## 预览为什么与真机对得上、拖转速不抖不闪

核心在 `src/gl/FanRenderer.ts` 的三通道物理模型：

1. **帧→扇形角区间积分**：每帧记录编码器脉冲模型下实际扫过的 `[thetaStart, thetaEnd]`，
   转速突变只改变后续帧区间，历史帧区间不回改，画面不拉伸不压缩。
2. **HDR 视觉暂留累积**：乒乓 FBO 上执行 `persist = persist·exp(-dt/τ) + pulse·k`，
   衰减系数按真实墙钟 `dt` 计算，与显示器帧率/rAF 间隔解耦，因此无频闪。
3. **转速归一化曝光**：单脉冲曝光与扇区角宽反比归一，稳态平均亮度在 300–1800rpm 全域恒定
   （自动化实测帧间亮度极差 ≤0.5/255，300rpm 低转速的轻微波动是真实物理频闪）。
4. **相位连续积分**：机械相位只累加不重置，滑杆改 rpm 仅改角速度 ω，杜绝跳变抖动。

## 固件包格式（.hol1）

小端字节序，96 字节定长包头 + RGB888 帧数据 + 4 字节 CRC32（IEEE 802.3，与 zlib 一致）。
包头含 Magic `HOL1`、序列号、扇叶直径、灯珠数、帧数/边长、帧率、目标转速、姿态补偿角、
安全半径、白平衡系数、标志位（白平衡/PWM/墙组包）。导出页内置回读解析与 CRC 自检。

