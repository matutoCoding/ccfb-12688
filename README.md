# 全息风扇内容编排与上机效果预览系统

浏览器端运行，TypeScript + WebGL2，素材全程本地处理（IndexedDB 持久化），产出文件直接交付客户。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产出 dist/，可整体交付部署
```

## 页面与功能

| 页面 | 覆盖功能点 |
|---|---|
| 素材库 | 视频入库、入点/出点裁剪、逐帧微调、源时间码记录、原片替换自动重链、.cube LUT 导入与多套调色方案切换对比、五星评分 + 时长区间筛选 |
| 画布编排 | 行业模板新建工程、占位框拖拽/缩放、片段分配后自动收进扇叶安全圆、模板版本更新提示同步 |
| 预览台 | 300–1800 RPM、顺/逆时针、视觉暂留成像仿真、电压波动/转速突变测试、PWM 非线性校正曲线（逐通道、CSV 校准表导入、分屏对比）、环境光断连告警、安全半径越界标红 |

## 预览与真机对齐的关键设计（不抖不频闪）

1. **相位累加**：灯带角度由 `performance.now()` 差值浮点累加，角速度对目标值做指数平滑（τ=0.25s）。拖转速滑杆或转速突变时相位连续，画面不跳。
2. **解析式余辉**：每个像素独立计算"灯带上次扫过本角度至今的时间"，按指数衰减加权。亮度是 (像素, 相位, 角速度) 的纯函数，不依赖历史帧累积，因此无帧间抖动与频闪。
3. **角度锁定**：内容按扇形角区间映射而非帧序号，转速漂移/突变时成像不拉伸不压缩（与真机编码器实测周期动态调整同理）。
4. **量化平滑**：角向按编码器分区、径向按灯珠数量化，边界 8%~10% 平滑过渡，保留真实扫描质感又避免边界爬行。

## 固件数据包格式（`HFAN` v1）

```
偏移  字段
0     魔数 'HFAN' (4B)
4     u16 协议版本 = 1
6     u16 头长 = 64
8     u16 灯珠数
10    u16 每圈分区数
12    u16 帧数
14    u16 帧率
16    u32 flags（bit0 白平衡已套用，bit1 PWM 已套用）
20    u32 负载字节数
24    u32 负载 CRC32
28    16B 设备序列号（ASCII，0 填充）
44    i32 姿态补偿角 ×100
48    u32 打包时间戳（unix 秒）
52    12B 保留
64    负载：帧 × 分区 × 灯珠 × RGB888
```

## 设备日志格式（U 盘回传）

CSV 每行一条：`素材编号,开始时刻ISO,结束时刻ISO,实测RPM`；也支持 JSON 数组。
导出中心按素材聚合上播次数/累计时长，工程外编号列为异常记录，可导出 HTML 验收报告。
